# Winners Chapel Issele-Uku

A responsive church website for Winners Chapel Issele-Uku, featuring Pastor Judah, service information, church gatherings, prayer details, and a five-slide photo carousel.

## Project Files

- `index.html` - page content and structure
- `style.css` - responsive layout and visual styles
- `script.js` - carousel controls and automatic slide rotation
- `assets/winners-chapel-logo.png` - church logo and favicon
- `assets/images/1.jpg` through `assets/images/5.jpg` - supplied church photos

## Preview Locally

Open `index.html` in a web browser, or use the Live Server extension in Visual Studio Code. No build step or package installation is required.

## Publish

### GitHub Pages

1. Push the project files and `assets` folder to a GitHub repository.
2. In the repository, open **Settings > Pages**.
3. Choose **Deploy from a branch**, select the `main` branch and `/ (root)`, then save.

### Netlify Drop

Open [Netlify Drop](https://app.netlify.com/drop) and upload the project folder. Keep `index.html`, `style.css`, `script.js`, and the `assets` folder together so the site can load its images and logo.
